# UI/UX Design System

## Product personality

Professional, trustworthy, clean, fast and business-focused.

Avoid:
- excessive gradients
- excessive animations
- clutter
- oversized decorative elements
- distracting effects

## Colors

Light dashboard:
- background: #F6F7F9
- surface: #FFFFFF
- primary text: #111827
- secondary text: #667085
- border: #E5E7EB
- primary action: #111827
- success: #16A34A
- warning: #D97706
- error: #DC2626
- info: #2563EB

Dark mode may exist for the dashboard. Printable invoices remain light.

## Typography

Primary font:
Inter

Fallback:
system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

Application:
- page title: 28px / 700
- section title: 20px / 600
- card title: 16px / 600
- body: 14px / 400
- small: 13px
- caption: 12px
- input: 14px
- label: 13px / 600
- table: 13px
- button: 14px / 600

Invoice:
- title: 18–22px bold
- business name: 16–20px bold
- normal text: 9–11px
- table: 9–10px
- totals: 11–13px bold
- footer: 8–9px

- keyboard navigation
- visible focus
- labels
- semantic controls

- adequate contrast
