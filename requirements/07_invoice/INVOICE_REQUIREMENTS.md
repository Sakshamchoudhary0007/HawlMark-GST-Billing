# Invoice Requirements

## Paper

Default:
- A4 portrait
- clean margins
- print-safe CSS

## Header

- TAX INVOICE
- business logo
- legal/trade name
- address
- contact
- GSTIN
- configurable licence information

## Buyer

- party/customer name
- address
- GSTIN
- licence number
- PAN where applicable
- place of supply

## Metadata

- invoice number
- invoice date
- place of supply
- reverse charge indicator where applicable
- reference/order number where applicable

## Items

Minimum:
- S.N.
- description
- HSN/SAC
- quantity
- unit
- rate
- amount

Optional configurable:
- discount
- taxable value
- GST rate
- CGST
- SGST
- IGST

## Taxes

Support:
- intra-state CGST + SGST
- inter-state IGST

The applicable tax mode must be stored with the invoice.

## Totals

- subtotal/taxable amount
- CGST
- SGST
- IGST
- round-off if configured
- grand total

## Amount in words

Generate from the final rounded amount using a tested deterministic service.

## Footer

- bank details
- terms
- declarations
- receiver signature
- authorized signatory

## Lifecycle

DRAFT → FINALIZED → CANCELLED

A finalized invoice is not an ordinary editable record.

## Invoice number

Generated by backend transactionally.

No duplicate invoice numbers within a business/numbering scope.

## Print

Dedicated print stylesheet hides navigation and editing controls.

## PDF

PDF must use the same invoice data source and reproduce the intended A4 layout.

## Internationalization

Invoice text may include English and Hindi. Use UTF-8/utf8mb4 throughout.
